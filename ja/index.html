よくある質問

画面をスリープさせないためのQ&A

電源設定を変えずに画面をスリープさせないには？

screenwakeup.com を開き「画面をスリープさせない」をクリック。Wake Lock API を使用し、システム設定を変更しません。

iPhoneとAndroidで使えますか？

はい。iOS Safari と Android Chrome で動作します。ブラウザのタブを開いたまま表示してください。

MacとWindowsで動作しますか？

はい。Chrome、Edge、Firefox、Safari すべてで動作 — インストール不要です。

Microsoft Teamsで離席中になるのを防ぐには？

screenwakeup.com でマウス移動シミュレートとF15キー送信を有効にし「画面をスリープさせない」をクリック。Teamsの非アクティブ検知を防ぎます。

Slackでアクティブ状態を維持するには？

F15キー送信を有効にしてください。55秒ごとにサイレントキーストロークを送り、Slackのアイドルタイマーをリセットします。

無料のオンラインポモドーロタイマーはありますか？

はい。ScreenWakeUp に内蔵ポモドーロタイマーがあります。🍅 ポモドーロをクリックすると25分作業・5分休憩サイクルが始まり、終了時にチャイムが鳴ります。

タイマーを設定できますか？

はい。30分、1時間、2時間、4時間から選択できます。またカスタムタイマーで任意の分数も設定可能です。

安全ですか？アカウントは必要ですか？

100%安全です。アカウント不要、登録不要、データ収集なし。すべてブラウザ内で動作します。
