よくある質問

画面をスリープさせないためのQ&A

電源設定を変えずに画面をスリープさせないには？

screenwakeup.com を開き「画面をスリープさせない」をクリック。Wake Lock API を使用し、システム設定を変更しません。

iPhoneとAndroidで使えますか？

はい。iOS Safari と Android Chrome で動作します。ブラウザのタブを開いたまま表示してください。

MacとWindowsで動作しますか？

はい。Chrome、Edge、Firefox、Safari すべてで動作 — インストール不要です。

Microsoft Teamsで離席中になるのを防ぐには？

screenwakeup.com で「画面をスリープさせない」をクリック。画面が点いたままになり、Teamsが離席中と判定する最大の原因であるロックやスリープを防ぎます。正直な注意点：ウェブサイトは本物のマウスやキーボード入力をシミュレートできないため（ブラウザがセキュリティ上ブロック）、完全な無操作が長く続くとTeams側の判定でステータスが変わる場合があります。

Slackでアクティブ状態を維持するには？

screenwakeup.com でPCをスリープさせないようにします。Slackはマシンが起動していてSlackが開いている間はアクティブと表示し、ステータスが変わるのはスリープや画面ロックのときです。正直な注意点：ブラウザから本物のキー入力を送ることはできません — それを謳うサイトは誇大表示です。

無料のオンラインポモドーロタイマーはありますか？

はい。ScreenWakeUp に内蔵ポモドーロタイマーがあります。🍅 ポモドーロをクリックすると25分作業・5分休憩サイクルが始まり、終了時にチャイムが鳴ります。

タイマーを設定できますか？

はい。30分、1時間、2時間、4時間から選択できます。またカスタムタイマーで任意の分数も設定可能です。

安全ですか？アカウントは必要ですか？

100%安全です。アカウント不要、登録不要。すべてブラウザ内で動作します。
